# Applied Statistics in R

## Overview

This project is a collection of R-based statistical analysis reports. The work focuses on applying core statistical methods to different datasets and interpreting the results in a clear, practical way.

The project includes hypothesis testing, correlation analysis, covariance, cosine similarity, confidence intervals, ANOVA, model comparison, and regression modeling.

## Project Files

- paired_t_test_candy_consumption.Rmd
- travel_insurance_correlation_analysis.Rmd
- travel_insurance_anova_analysis.Rmd
- housing_price_regression_analysis.Rmd

## Analyses Included

### Paired T-Test Analysis

This report analyzes whether children consumed more candy corn while watching TV compared to not watching TV. The analysis calculates the mean difference, standard deviation, variance, t-statistic, p-value, and confidence interval.

### Travel Insurance Correlation Analysis

This report uses travel insurance data to examine relationships between variables such as age, duration, net sales, and commission. The analysis includes Pearson, Spearman, and Kendall correlations, covariance, cosine similarity, and confidence intervals.

### Travel Insurance ANOVA Analysis

This report uses travel insurance data to evaluate how product name, distribution channel, and agency type relate to net sales. The analysis applies ANOVA and compares models using AIC.

### Housing Price Regression Analysis

This report uses a housing dataset to explore predictors of home prices. The analysis includes data exploration, transformation, simple linear regression, multiple linear regression, and model comparison.
